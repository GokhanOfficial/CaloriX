# Android Zorunlu Güncelleme Mekanizması (GitHub Releases + minVersion mantığı)

## Mimari özet
- **Barındırma**: APK + `latest.json` GitHub Releases'ta (repo public → token gerekmez). Kararlı manifest URL'si: `https://github.com/GokhanOfficial/CaloriX/releases/latest/download/latest.json` (API/rate-limit yok, tag bilmek gerekmez).
- **latest.json şeması**: `versionName`, `versionCode`, `minSupportedVersionCode` (DB migration'ı geldiyse altı çalışmaz), `apkUrl`, `sha256`, `notes {tr,en}`, `releasedAt`.
- **Karar mantığı** (cihazın build numarası `package_info_plus` ile):
  - `deviceCode < minSupportedVersionCode` → **ZORUNLU**: açılış engellenir, tam ekran "Güncelleme gerekli" sayfası (Güncelle → tarayıcıda APK URL'si `url_launcher` ile; Yeniden kontrol et). Geçiş yolu yok.
  - `deviceCode >= minSupportedVersionCode` ama `< versionCode` → **OPSİYONEL**: atlanabilir dialog (sürüm başına bir kez hatırlat, SharedPreferences'a dismissed-code yaz).
  - eşit → güncel, hiçbir şey görünmez.
- **Çevrimdışı / kontrol başarısız**: SharedPreferences'a cache'lenen son manifest kararı verir; cache de yoksa uygulama **uyarıyla açılır** (tek seferlik "güncelleme kontrolü yapılamadı" snack'ı) — çevrimdışı kullanıcı kilitlenmez.
- **Platform**: Android'e özel; web/iOS'ta kontrol no-op (`kIsWeb` guard, iOS klasörü zaten yok).

## 1. Flutter — yeni dosyalar (`lib/core/updates/` + `lib/features/updates/`)
- **`update_manifest.dart`** — `UpdateManifest` modeli + `fromJson`; `required/optional` kararını veren saf fonksiyon (test edilebilir).
- **`update_checker.dart`** — Riverpod `StateNotifier<UpdateStatus>` (`upToDate | optional | required | unknown`): `http` ile manifest çeker, hata halinde cache'ten karar verir, cache'e yazar. Opsiyonel dismiss'i prefs'e yazar.
- **`update_gate.dart`** — `MaterialApp.router`'ın `builder`'ına sarılan kök widget: `required` → `ForceUpdatePage`'i çocuğun yerine gösterir; `optional` + dismiss edilmemiş → dialog; `unknown` + ilk kez → uyarı snack'ı. Kontrolü build'de tetikler (web'de no-op).
- **`force_update_page.dart`** — engelleyici tam ekran: uygulama logosu, çevrili başlık/gövde + release notes, "Güncelle" (tarayıcı) ve "Yeniden kontrol et" butonları.

## 2. Flutter — değişen dosyalar
- `pubspec.yaml`: `package_info_plus: ^8.x`, `http: ^1.x` ekle.
- `app_constants.dart`: `updateManifestUrl` sabiti.
- `app.dart`: `MaterialApp.router`'a `builder: (_, child) => UpdateGate(child: child!)` ekle.
- `assets/translations/*.json` ×12: `updates.*` anahtarları (requiredTitle/Body, optionalTitle/Body, updateNow, later, recheck, checkFailed, notesTitle).
- `test/core/updates/update_manifest_test.dart`: karar mantığı testleri (zorunlu/opsiyonel/güncel sınırları, bozuk JSON).

## 3. Yayınlama scripti — `tool/release_android.sh` (tool/ dizini mevcut)
1. `flutter_app/pubspec.yaml`'dan version + build numarasını oku (argüman yoksa hata ver).
2. `flutter build apk --release` (flutter_app içinde).
3. `sha256sum` hesapla; `latest.json` üret — `minSupportedVersionCode` **`--min-code N` argümanıyla** (default: mevcut build, yani sadece eski herkes opsiyonel görür; DB migration'ı varsa cutoff build'i geç).
4. `gh release create "android-v{version}+{build}" app-release.apk latest.json --title --notes` (tag'deki `+` URL-encode'lu apkUrl JSON'a yazılır).
5. Kararlı URL'yi `curl -sI` ile doğrula (200 değilse uyar), özet yazdır.
- Not: mevcut `flutter.yml` CI AAB üretiyor (Play Store için) — dokunulmaz; script lokal APK akışı.

## 4. Dokümanlar
- `README.md` / `README_EN.md`: "Sürüm Yayınlama (Android)" bölümü — pubspec version bump → `tool/release_android.sh --min-code N` → release. min-code'un DB migration bağlantısı örneğiyle anlatılır (örn. barcode migration'ı gibi bir şema değişikliğinde cutoff konur).
- `CHANGELOG.md`: özelliği belirten kısa giriş.

## 5. Doğrulama (build yok — canlı test senin tarafında)
- `flutter analyze` temiz + `flutter test` (yeni karar-mantığı testleri dahil).
- `bash -n tool/release_android.sh` sözdizimi kontrolü.
- İlk gerçek release'i sen çalıştırınca: eski APK'lı cihazda zorunlu/opsiyonel akışını canlı doğrula (script'in 5. adımı URL'Ï otomatik doğrular).
